# RVSMPS - Glam Pro AI

An intelligent salon and retail business management platform automating bookings, billing, and client workflows.

## Key Features
- **Smart Appointment Scheduling**: Interactive calendar and booking system.
- **Claude-Powered Client Copilot**: Automated appointment assistance and client consultation summaries using Claude API.
- **Billing & Invoicing**: Instant invoice generation and receipt management.
- **Admin Dashboard**: Real-time sales analytics and staff performance metrics.

## Tech Stack
- **Frontend**: React, TailwindCSS, Vite
- **Backend**: Node.js, Express
- **AI / LLM**: Anthropic Claude API
- **Deployment**: Vercel (`rvsmps.store`)
